# 校园创意验证 Agent 编排平台（MVP）

一个用于展示 Agent 编排闭环的本地网页应用。面向校园里的个人创意者，把真实需求整理成小规模验证计划与项目方案，并由独立检查步骤核对证据边界和必需章节。

> 已依据用户提供的《未来杯创新大赛赛制介绍及赛题说明会》PPT 核对赛题一：第五届未来杯“Agent 编排创新应用”。初赛提交要求为不少于 5000 字 PDF 方案书、10–15 页 PPT、3–5 分钟演示视频，以及可复现的源码仓库或在线演示。截止日为 2026-11-20。具体报名资格、系统字段和提交时刻请以官网平台为准。

## 功能

- 规划 Agent：把用户需求整理成假设与验证步骤。
- 方案 Agent：生成结构化项目方案，缺证据时明确标注待验证。
- 独立验证 Agent：检查章节完整性和证据表达。
- Self-Loop：真实模型未通过检查时按反馈修订，最多 2 次。
- 运行日志：显示各阶段状态、说明、耗时。
- 内置本地指南：按关键词检索访谈、原型测试、指标设计、隐私保护条目，并传给规划与方案 Agent；不联网。
- 动态派发：依据任务所需能力、注册 Agent 能力、配置负载和优先级选择候选角色，并记录派发理由。注册表可编辑，当前流程仍是依赖约束的顺序执行。
- 方案场景目前是“校园创意需求验证”；Agent 角色和工作流目前在代码中固定，尚无可视化工作流编辑器、Agent 动态注册/版本管理、外部工具/MCP、向量检索或持久记忆。
- 两种运行模式：模拟模式不调用模型；真实模式使用 OpenAI Chat Completions 兼容接口。
- 下载 Markdown 报告和 JSON 运行记录。

模拟模式是固定逻辑演示，**不是真实模型输出，也不代表真实模型能力**。真实模式可连接 OpenAI 或兼容服务。API Key 仅从环境变量读取，不保存在应用代码或下载报告中。

## 启动（macOS）

1. 安装 Python 3.10 或更新版本。
2. 双击 `启动应用.command`；首次运行会创建本地虚拟环境并安装依赖。若 macOS 阻止脚本启动，可在终端中进入此文件夹并运行 `./启动应用.command`。
3. 或按下面步骤手动启动。
4. 在本文件夹打开终端，执行：

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   streamlit run app.py
   ```

5. 浏览器打开 Streamlit 显示的本地地址。默认使用模拟模式，无需 API Key。

## 连接真实模型

你暂时不需要先会写代码或把密钥发给别人。先选择一家你能注册并开通 API 的模型服务，确认它提供 OpenAI Chat Completions 兼容接口，再在自己电脑按下面步骤配置。模型服务商、模型名称、接口地址和费用由你开通的服务决定；默认值只是示例。

先在终端设置环境变量，然后从同一终端启动应用：

```bash
export OPENAI_API_KEY="你的密钥"
export OPENAI_BASE_URL="https://api.openai.com/v1"
export OPENAI_MODEL="gpt-6-luna"
streamlit run app.py
```

`OPENAI_BASE_URL` 应是服务商的 API 根地址；应用会追加 `/chat/completions`。默认模型示例为 `gpt-6-luna`，只有在服务商明确支持该模型且你的账户有权限时才能使用。不同服务的模型名、鉴权方式和返回格式可能不同；若服务商不兼容 Chat Completions 格式，需要调整 `LLMClient`。不要把真实 Key 放进截图、报告或提交仓库。密钥只留在你自己的电脑环境变量中。

## 使用方法

填写一个校园需求、目标用户和可选的已有证据，点“运行 Agent 编排”。运行后检查计划、验证报告、最终方案和流程日志。对模拟结果可下载报告；报告会写清楚运行模式。真实模型的输出必须人工核验，尤其是事实、成效和合规内容。

## 项目结构

```text
app.py          Streamlit 页面入口
core.py         Agent 编排、模型接口、本地指南检索
scheduler.py    Agent 注册表读取与能力匹配派发
agent_registry.json  可编辑的 Agent 能力、负载和版本配置
knowledge_base.json  本地项目验证指南（可按相同字段扩充）
requirements.txt
.env.example    环境变量示例（不含密钥）
```

## 当前范围与后续

这是单机 MVP，不含用户账号、云端部署、外部搜索、文件知识库或多人协作；内置指南采用本地关键词检索，不是向量数据库或外部 RAG 服务。当前“独立验证”在模拟模式是确定性规则，在真实模式由第二次模型调用完成；它不是形式化事实核查。赛题一还要求完整的平台级编排能力；当前版本已实现基于能力、优先级和配置负载的角色派发，并可编辑 Agent 注册表；仍未覆盖可视化工作流设计、Agent 在线动态注册、并行/DAG调度、MCP/外部工具集成和并发/压力评测。提交前应优先补齐能实际演示的调度与工具集成，并在方案、PPT、视频和源码仓库中保持功能描述一致。


## 自检

无需 API Key 可先运行 `python -m unittest -v`，检查模拟流程、Self-Loop 上限、API 请求组装和缺少密钥时的提示。测试中的 API 返回内容由本地替身提供，不会调用真实模型服务。
