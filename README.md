# 有据：AI 简历筛选助手

**有据**是一款本地运行的简历筛选原型。它把模型限制在“整理简历事实、提供原文依据”的角色，由明确的程序规则计算匹配分数；没有足够证据时显示“待核实”，并保留人工最终决定权。

> 本项目用于演示和辅助复核，不应单独用于招聘录用或淘汰决定。尚未完成真实招聘数据评测、公平性评估或生产环境安全审查。

## 参赛作品的设计重点

常见的 AI 简历筛选演示会让模型直接给候选人打分。本项目尝试把“读简历”和“做评分”分开：

- 模型从 PDF/TXT 简历中抽取结构化信息，并为判断附上简历原句。
- 程序验证引文能否在原文中定位，再由确定性评分引擎按岗位设置计算分数与排序。
- 没有提及或证据无效的项目标为“待核实”，不当作不符合，也不纳入该项得分。
- 复核模块可以提示信息缺失、明确不匹配和证据问题，但不能改写评分结果。
- 批量处理会记录阶段、错误、重试与耗时，方便检查流程是否真实完成。

这是一项可解释性设计主张，不代表系统已经证明比人工或其他筛选方式更准确、更公平。真实模型质量和招聘效果仍需独立评测。

## 功能与流程

岗位要求设置 → 上传多份 PDF/TXT 简历 → 文本提取 → 结构化抽取 → 原文证据校验 → 确定性评分 → 排序 → 人工复核建议。

评分维度权重：必备技能 50%、加分技能 10%、工作经验 20%、学历 10%、证书 10%。信息不足的维度不按零分处理，并另行显示信息完整度。权重和规则是当前原型设定，需由招聘专业人员和真实评测进一步验证。

系统还保留了早期校园创意验证 Agent，入口为 `app.py`。仓库里原有的校园项目方案书和演示材料对应这个旧模块，不是当前简历筛选产品的评测材料。

## 本地运行

需要 Python 3.10 或更新版本。macOS / Linux：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run screening_app.py --server.address 127.0.0.1 --server.port 8501
```

浏览器打开终端显示的本地地址。默认模拟模式不调用外部模型 API；它只用于演示界面和本地流程，不能说明真实模型效果。

## 配置真实模型（可选）

复制 `.env.example` 为 `.env`，再填写你自己的服务商 API Key。百炼 Qwen 可用以下配置：

```dotenv
OPENAI_API_KEY=在本机填写你自己的密钥
OPENAI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
OPENAI_MODEL=qwen-plus
```

在项目目录运行 `启动招聘筛选.command`，或在终端先加载 `.env` 再启动：

```bash
set -a
source .env
set +a
streamlit run screening_app.py --server.address 127.0.0.1 --server.port 8501
```

`.env` 已加入 Git 忽略规则。**不要把真实简历或 API Key 提交到仓库、截图或聊天中。**真实模型模式会将简历文本发送到你配置的模型服务商；上传真实个人简历前，请先取得适当授权并确认该服务的数据处理方式。

## 主要模块

| 文件 | 职责 |
|---|---|
| `screening_app.py` | 招聘筛选网页与结果展示 |
| `screening_orchestrator.py` | 编排解析、抽取、评分、复核与汇总 |
| `screening_scheduler.py` | 批量调度、并发与运行轨迹 |
| `screening_extraction.py` | 模型抽取结果清洗及证据处理 |
| `screening_extractors.py` | PDF/TXT 文本读取 |
| `screening_models.py` | 岗位、简历、证据和评分数据结构 |
| `matching.py` | 确定性评分、状态判断和排序 |
| `screening_reviewer.py` | 人工复核提示；不负责改分 |

## 已知限制

- 当前是单机原型，岗位和流程能力有限，没有账号、云端部署或招聘系统集成。
- 原文引句能定位不代表简历陈述真实，也不能保证模型理解正确。
- 技能别名、岗位权重和评分阈值仍需专业人员验证。
- 尚无公开基准集、盲测结果、招聘人员试用结果或公平性评测。
- 不应把分数直接当作录用建议；任何筛选结果都需要人类复核。
